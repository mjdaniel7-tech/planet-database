# Planet Database

A Python project that demonstrates database management concepts using information about the planets in our solar system.

## Overview

This project stores and manages planet data using Python and a database. It demonstrates fundamental programming and database skills while providing an expandable foundation for future development.

## Features

- View planet information

- Search for planets by name

- Update planet records

- Track revision history

- Preserve historical data (such as Pluto's reclassification)

- Unit testing

## Technologies Used

- Python 3

- MySQL (or SQLite during development)

- SQL

## Future Enhancements

- Add all known moons

- 3D rotating solar system visualization

- AI-powered natural language search

- Web interface

- Statistics and reporting dashboard

## Learning Goals

This project demonstrates:

- Python programming

- Database design

- SQL queries

- CRUD operations

- Data integrity
